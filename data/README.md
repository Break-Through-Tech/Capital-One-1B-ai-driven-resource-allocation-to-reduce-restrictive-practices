# How to Access CRDC Documentation and Data

Use the following steps to access the Civil Rights Data Collection (CRDC) data and documentation needed for this project.

## 1. Navigate to the CRDC Data Page

Go to the [Civil Rights Data Collection (CRDC) dataset on Data.gov](https://catalog.data.gov/dataset/civil-rights-data-collection-crdc).

## 2. Open the CRDC Landing Page

Click on the **Landing Page** link provided on the Data.gov page.

## 3. Download the Data Files

Under **Downloadable Data Files**, download the following years:

- **2021–2022**
- **2020–2021**
- **2017–2018**
- **2015–2016**

These files will be used as the primary data sources for the project.

## 4. Review the Data Definitions

For each year, use the **data definitions** provided in the table on the CRDC landing page to understand the variables included in the dataset.

Be sure to review the definitions for the variables you plan to use before beginning your analysis.

## 5. Explore Additional State and National Data

The CRDC landing page also provides links to **State Data** and **National Data**. You can use these links to download more specific or detailed information if needed for your analysis.
